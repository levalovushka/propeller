# AX-трассы для решения `CallWindowJournal`

Формат: JSONL, одна строка — один опрос дерева (`{"t": секунды, "tiles": [...]}`),
первая строка — метазапись, решение её пропускает. Пишется командой
`axprobe trace` (`tools/diarize-lab/axprobe`), поля плитки — контракт с
`CallWindowJournal.Tile`.

**Все трассы здесь синтетические**: написаны руками по замеренной геометрии
из `tools/diarize-lab/DIARIZATION.md` H12 (плитка говорящего 1080×600 против
160×80 у молчащего, 720×400 в переходе, формат `AXDescription`
`«Имя, звук, видео»`). С живой встречи не снято ни одной — живые трассы
содержат имена настоящих людей и живут вне репозитория, в
`~/diarize-lab-corpus/`, рядом с отчётами axprobe.

| файл | что изображает | что обязано выйти |
|---|---|---|
| `synthetic-two-speakers.jsonl` | вид «Динамик»: двое по очереди, переход через равные плитки | два пролёта по площади, переходный опрос — молчание |
| `synthetic-gallery-marker.jsonl` | вид «Галерея» по живой трассе 2026-08-20: равные плитки, метка `active speaker` у ровно одной, выброс на один опрос | четыре пролёта по метке, выброс отброшен |
| `synthetic-screen-share.jsonl` | демонстрация экрана: плиток нет, потом одна плавающая без метки | журнал пуст |
| `synthetic-no-meeting.jsonl` | Zoom открыт, встречи нет | журнал пуст |
