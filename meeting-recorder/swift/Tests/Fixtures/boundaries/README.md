# Записанные ответы границ

Каждый файл — то, что реально приходило от `gigastt` или Ollama в инциденте из
`STATE.md`. Держим их как файлы, а не строки в тестах, чтобы новый случай
добавлялся копированием тела ответа, без правки кода.

| Файл | Инцидент |
|---|---|
| `asr-ok.json` | норма: сегменты с таймингами |
| `asr-words-only.json` | старый билд gigastt: только `words`, без `segments` |
| `asr-text-only.json` | ещё более старый: голая строка |
| `asr-413.txt` | 43-минутная встреча, ~79 МБ → body limit; транскрипт был потерян |
| `asr-error-envelope.json` | сайдкар вернул свою ошибку в теле |
| `asr-empty.json` | 200 OK, но говорить не о чем (пустой system-стем) |
| `chat-ok.json` | норма |
| `chat-thinking-only.json` | qwen3.5 ушёл в рассуждения: 484 с, 12794 токена, пустой `content` |
| `chat-empty.json` | ответил пустотой без рассуждений |
| `chat-malformed.json` | не тот JSON (обрезанное тело / страница прокси) |
| `chat-collapsed-digest.json` | режим схлопывания свода: 351 токен при пороге 800, документ на четыре пункта (числа A5.1, `13k-h`) — вход гварда `RecapDigestGuard` |
