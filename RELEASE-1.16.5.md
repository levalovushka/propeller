Основание — замеры в [tools/recap-lab/OPTIMIZATION.md](tools/recap-lab/OPTIMIZATION.md):
t=0 детерминирован побайтово на двух встречах (A4), механическая сборка спасает
3–5 пунктов на схлопнувшихся сводах (A5.1) и не может схлопнуться сама.

## Что едет

| изменение | что даёт |
|---|---|
| `temperature 0` + один ретрай при t=0,3, если ответ схлопнулся | пол поднимается с 4 до 8 пунктов, результат воспроизводим. Пол держится **только вместе с ретраем** (риск №1 ниже) |
| механическая сборка facts → конспект (встречи, не влезающие в окно) | свод больше не схлопывается: в нём нет генерации |
| версия генератора в метаданных конспекта | телеметрия по версиям, безопасный бэкфилл, откат |
| телеметрия генерации | reply_tokens, retried/collapsed, длительность, число пунктов, версия, RAM-когорта |
| прогресс по чанкам в UI на пути нарезки | долгая генерация не выглядит зависанием |

## Что НЕ едет (решено, не забыто)

- **Ансамбль — срезан целиком** (решение владельца 2026-08-14) и вернулся на
  доску. Условие возврата любой многовызовной конструкции в релиз: покрытие
  выше базы **и** читаемость у независимого судьи не ниже базы. Матчерное
  покрытие без читателя один раз уже обмануло — этим правилом урок зафиксирован.
  Лид «свободные окна, 4 вызова» (доска, B0/«Что дальше» п. 4) живёт там же
  и меряется только под это условие.
- Порог 15 минут и маршрутизация по RAM — не нужны без ансамбля: путь один для
  всех машин.
- Облачный провайдер как opt-in тир качества — **решение владельцем не принято**,
  вне этого релиза.
- Старые конспекты не перегенерируются **никогда** — ни бэкфиллом, ни вручную.
  Бэкфилл догоняет только встречи без конспекта.
- Кнопки «Сгенерировать заново» нет и не появляется: при t=0 повтор — тот же текст.
- Выдумки не чиним — только считаем в телеметрии.
- 9B не тащим: +0,7 пункта в честном замере (p = 28 %) не стоят 3,2 ГБ
  (OPTIMIZATION.md, пункт «б»).

## Правила маршрутизации

| встреча | путь |
|---|---|
| влезает в окно | одиночный проход, t=0 + ретрай |
| не влезает в окно | нарезка + механическая сборка |
| notes пользователя | текст заметок не переписывается (правило наследуется); одиночный путь — поведение 1.16 не меняется |

## Решения до старта порта

- [x] Выдумки: только детектим в телеметрии, не чиним (решено 2026-08-13).
- [x] **Дубль лучше пропуска — почти всегда** (решено владельцем 2026-08-14).
      Пропуск невидим и нечиним читателем; дубль виден и стоит лёгкого
      раздражения. В lite живёт в механической сборке: при неуверенности
      «дубль или потеря» — дубль. Граница — бюджет буллетов: внутри бюджета
      жадный отбор предпочитает новое повторному.
- [x] Ретраев у одиночного пути — **один** (замер A5.2 показал, что порог берут
      2 сэмпла из 5, но растить хвост попыток вслепую не будем): телеметрия
      `collapsed` покажет масштаб на проде, решение о втором ретрае — по ней.
- [ ] Notes на пути нарезки: свод теперь механический, вставлять заметки
      генерацией некуда. Дефолт — отдельным блоком в документ, без переписывания;
      подтвердить при порте.

## Риски, известные до старта

**1. У `t=0` есть режим конфабуляции, и детерминизм его запирает.** На
`20260810_094722` детерминированный ответ придумывает участника («Ильяс» →
«Илья Сафронов», пять вхождений, ему назначаются задачи); повтор при t=0 вернёт
то же слово в слово. Строка «пол 4 → 8» держится только вместе с ретраем.

**2. Дыра, которая есть в проде уже сегодня.** Одиночный путь имена не
фильтрует: выдуманная фамилия доезжает до пользователя как есть. В lite это
осознанно не чинится (см. «Что НЕ едет») — только телеметрия.

**3. Кандидат в телеметрию:** доля имён конспекта без кандидата ближе θ = 0,343
(нормализованное редакционное расстояние до токенов транскрипта и шапки).
Считается без модели; как относительный риск-сигнал откалиброван пробой C-2
(`tools/recap-lab/probes/PROBES.md`). В гейты не входит.
