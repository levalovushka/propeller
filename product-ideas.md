## Отложено

| Идея | Причина отложить | Когда вернуться |
|---|---|---|
| Консолидация диаризации на gigastt (убрать FluidAudio) | People-library на FluidAudio-embeddings | v2, если FluidAudio плох на реальных Zoom |
| Нативные Rust-биндинги gigastt вместо HTTP-sidecar | Swift-биндинги «in progress»; HTTP проще | Когда биндинги стабильны или sidecar мешает |
| Автодетект браузерных встреч (Meet, Телемост) | Сложнее детекта процесса; хватит ручного старта | v2, по фидбеку |
| Авто-обновления через Sparkle | Мало сотрудников — проще переслать новый DMG | Если раздача вырастет |
| Developer ID + нотаризация | Не блокер при ручной раздаче DMG; ad-hoc + «ПКМ → Открыть» | Если Gatekeeper мешает коллегам |
| Интеграция с Vault | Личный сценарий | После v1, вне приложения |
| Real-time субтитры | Батч покрывает ценность | По запросу |
| Полноценный редактор заметок «пока говорят» | Закрыто более узкой идеей «заметки по хоткею» | Если понадобится богатый редактор сверх шортката |
| Экспорт в docx/txt | Сначала проверить .md | По фидбеку после пилота |
