## Отложено

| Идея | Причина отложить | Когда вернуться |
|---|---|---|
| Консолидация диаризации на gigastt (убрать FluidAudio) | FluidAudio работает и изолирован; People-library больше нет (её embeddings уже не держат) | Если gigastt-diar станет надёжнее на реальных Zoom |
| Нативные Rust-биндинги gigastt вместо HTTP-sidecar | Swift-биндинги «in progress»; HTTP проще | Когда биндинги стабильны или sidecar мешает |
| Замер пика памяти на 8 ГБ Mac и сравнение с 1.16.4 | Решение владельца 2026-08-19: провести не сможем — нужен чужой Mac на 8 ГБ и кит 1.16.4, которых нет. Всплывал трижды в хвостах 15–16 августа, поэтому записан здесь, а не заведён задачей | Если такой Mac окажется под рукой у тестера |
| Автодетект браузерных встреч (Meet, Телемост) | Сложнее детекта процесса; хватит ручного старта | v2, по фидбеку |
| Интеграция с Vault | Личный сценарий | После v1, вне приложения |
| Real-time субтитры | Батч покрывает ценность | По запросу |
| Полноценный редактор заметок «пока говорят» | Закрыто более узкой идеей «заметки по хоткею» | Если понадобится богатый редактор сверх шортката |
| Экспорт в docx/txt | Сначала проверить .md | По фидбеку после пилота |

## Убито

| Идея | Причина |
|---|---|
| **Библиотека голосов / People / voice-matching** | plan-v2 Job 3: install & forget; спикеры «тупо и надёжно» — консистентные `Speaker N` + владелец-по-микрофону. Вырезаны `PeopleStore`, `PeopleSheet`, `SpeakerConfirmationView`, вкладка Speakers (~2000 строк) |
| **Опознание спикера по голосу** (любой возврат) | Остаётся убитым и после решения 2026-08-18 завести людей: механизмом там календарь, а не акустика. Замер: имена из речи не вытащить — 9 упоминаний на 769 реплик, главный голос встречи не назван ни разу (`tools/diarize-lab/DIARIZATION.md`) |
| Пост-транскрипционный опрос «опознай спикеров» | Противоречит install & forget; транскрипт теперь всегда авто-сохраняется |
| Облако, аккаунты, синк | Локальность и приватность |
| **Авторизация в Zoom / Meet ради состава и спикеров** | Проверено по документации 2026-08-19 (H13). У участника, который не хост, нет ни одного пути к таймлайну говорения: Apps SDK — Host/Co-Host, Report API — админский скоуп и Pro+, speaker timeline — Business+ и запись в облако хоста, RTMS — публичный вебхук, бэкенд и платные кредиты, Meet Media API — все участники в Developer Preview. Конституция не мешает (§3.4), ломается об install & forget и об роль |
| Мультиязычность сверх русского | GigaAM — ru; встречи почти все на русском |
| Homebrew tap как канал раздачи | Хватит DMG |
