# Dogfood checklist — перед раздачей коллегам (SHIP-08)

Любой fail = will-hurt. Отмечай вручную.

## Happy path
- [ ] Cold start → permissions → имя → Zoom 3–5 мин → Summary → Copy
- [ ] Нет Ollama/ключа → Summary показывает что делать + тост, не пустоту без объяснения

## Детект и очередь (постоянные сценарии)
- [ ] Звонок в **Контур.Толк** → запись стартует сама (если не сработало — снять `./tools/detect-meeting-signals.sh толк talk kontur` во время созвона)
- [ ] Zoom детектится; холостые панели («Настройки», «Чат») запись **не** запускают
- [ ] Начался звонок, пока шло саммари прошлой встречи → генерация встала, GPU свободен; после звонка догналась сама
- [ ] Переименование встречи **не** запускает перегенерацию саммари
- [ ] Есть бэклог без саммари + закончил новую встречу → новая получает саммари первой
- [ ] Настройки → «Проверить сейчас» называет платформу, а не всегда «Zoom»

## День менеджера (пакет D)
- [ ] Второй Zoom, пока первый ещё Transcribing/Summarizing → оба получают transcript+summary
- [ ] Во время ASR открыть старый митинг — нет чужого спиннера
- [ ] Запись + ⌃⌥N заметка + Stop → заметка на месте
- [ ] Play на A → запись B → Play на B играет B
- [ ] Upcoming mute → Zoom этой встречи **не** пишется
- [ ] Auto-record → Discard из окна / menu bar → нет файла в списке
- [ ] Quit mid-recording → relaunch → файл есть → Transcribe / auto-reconcile
- [ ] Mic-only встреча → бейдж только на ней

## Поставка
- [ ] DMG открывается, drag в Applications работает
- [ ] Первый запуск на чистом Mac — двойной клик, без ПКМ→Открыть и без сети
      (тикет застейплен внутрь `.app`, не только в образ)
- [ ] `gigastt` внутри `.app` (`Contents/MacOS/gigastt`)

## Релиз 1.16.5 · Г3 — прогонка саммари-lite руками (дополняет RELEASE-1.16.5.md)

Перед началом — снять слепок конспектов, после апдейта сравнить (пункт
«старые нетронуты байт-в-байт»):

```bash
shasum ~/.meeting-recorder/meetings/*-recap.md > ~/Desktop/recaps-before.sha
```

```bash
shasum -c ~/Desktop/recaps-before.sha | grep -v ": OK"
```

Смотреть за генерацией во время сценариев (фрагменты, решение гварда свода,
«ответ схлопнулся»):

```bash
/usr/bin/log stream --level debug --style compact --predicate 'subsystem == "app.propeller"'
```

- [ ] Обычная встреча → конспект есть, «Итог» есть. Детерминизм t=0 в
      приложении не проверить (кнопки перегенерации нет по решению) — закрыт
      стендом 2026-08-15: `tools/recap-lab/out/v2-compare/`, тот же вход → тот
      же текст
- [ ] **Длинная встреча (не влезает в окно, ~1,5 ч+)** — главный пункт, никто
      ещё не видел глазами: прогресс «фрагмент N из M» в деталях активности,
      конспект **авторский свод с «Итогом»** (не безавторская сборка), в логе —
      решение гварда. Если гвард отдал сборку — это лог-строка, а не молчание
- [ ] Встреча с заметками (⌃⌥N) → блок заметок в документе дословно
- [ ] Тишина / запись без речи → честный отказ, не мусор
- [ ] Kill приложения посреди генерации → рестарт → догнал сам, дублей и битых
      файлов нет (`ls -la` по встрече)
- [ ] Живая запись стартует во время бэкфилла → запись не страдает, генерация
      встала и догналась (лог: приоритет живой записи)
- [ ] Ollama стартует под hardened runtime — в логе `using llama-server for
      model` на первом же саммари
- [ ] Sparkle-апдейт **с реально установленной ad-hoc 1.16.x** (смена
      подписанта, риск №3) → апдейт встал; TCC (микрофон, календарь) спросят
      заново — это ожидаемо, идентичность сменилась
- [ ] После апдейта — `shasum -c` выше: пусто (все OK)

Примечание к Г5 (критерий отката): `collapsed=1` на крошечных записях —
ложная тревога по построению (пол 800 токенов рассчитан на настоящую встречу;
двухминутная запись 14.08 дала reply_tokens=190, collapsed=1 при живом
конспекте из 2 пунктов). Долю схлопываний в проде смотреть **только по встречам
от ~10 минут**, иначе тестовые огрызки замусорят метрику.

## Definition of Done
5 коллег × 1 неделя × ≥1 саммари каждый без пинга автору.
