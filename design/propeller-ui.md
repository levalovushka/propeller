# Propeller — спека интерфейса

_Как приложение должно выглядеть после редизайна (v2). Референс архитектуры — talat (скриншоты в [refs/](refs/)), но исполнение полностью нативное: системные шрифты, цвета и компоненты macOS. Название приложения — **Propeller** (переименовано из Meeting Recorder)._

## Принципы

1. **Архитектура talat, материалы Apple.** Берём у talat структуру и навигацию (sidebar → контент → правая панель, табы внутри встречи, command palette, двухуровневые настройки). Не берём: кастомные шрифты (у talat serif-заголовки), собственную тёмную палитру, нестандартные контролы.
2. **Только системное.** SF Pro через семантические стили (`.largeTitle`, `.headline`, `.body`, `.caption`), semantic colors (`.primary`, `.secondary`, `Color.accentColor`), материалы (`.ultraThinMaterial`, sidebar material), стандартные SwiftUI-компоненты: `NavigationSplitView`, `List`, `Picker`, `Toggle`, `Table`. Тема — системная (light/dark сами собой).
3. **Локальность видна.** Никаких «7h left»-лимитов и лицензий — приложение локальное, статусная зона показывает только запись/обработку.

## Структура главного окна

Три колонки (`NavigationSplitView`), как в talat:

```
┌───────────┬────────────────────────────────┬──────────────┐
│ Sidebar   │ Контент                        │ Правая панель │
│           │                                │ (контекстная) │
│ БИБЛИОТЕКА│  Заголовок встречи + дата      │ Участники     │
│  Встречи  │  Плеер с волновой формой       │  Микрофон: я  │
│  Summaries│  ─ Табы ─────────────────────  │  Систем. звук:│
│  Поиск ⌘K │  Транскрипт│Заметки│Рекап      │   спикеры     │
│           │  ...контент таба...            │ Теги          │
│ ПРИЛОЖЕНИЕ│                                │               │
│  Настройки│                                │               │
└───────────┴────────────────────────────────┴──────────────┘
          Верхняя панель: справа кнопка ● Запись (toolbar)
```

### Sidebar (слева)

- Секция «Библиотека»: **Встречи** (дефолт), **Summaries**, **Поиск**. _(Раздел «Люди» вырезан — plan-v2 Job 3.)_
- Секция «Приложение»: **Настройки**.
- Стандартный macOS sidebar (полупрозрачный материал, SF Symbols: `waveform`, `doc.text`, `magnifyingglass`, `gearshape`).
- Список встреч — внутри раздела «Встречи» второй колонкой (как сейчас), группировка Сегодня/Вчера/Неделя.
- **Summaries**: вторая колонка — встречи, у которых есть саммари (файл recap) и/или заметки. Деталь — только **Summary + Notes** (без транскрипта); клик «Open meeting» / выбор во Встречах открывает полный набор табов.

### Встреча (контент)

- Шапка: дата + время capsule, редактируемый заголовок (`.title2`), статус-pills (Transcribed / Saved / Recap) как сейчас.
- Плеер: волновая форма на всю ширину (вместо текущего тонкого прогресс-бара), клик = seek. Отрисовка — своя, цвета системные (`.quaternary` фон, `Color.accentColor` прогресс).
- Табы (`Picker` `.segmented`): **Transcript** / **Notes** / **Summary** (бывший Recap). Таб «Actions» из talat не берём.
  - Transcript: аватары, таймкод, переназначение спикера.
  - Notes: свободный текст; пишутся и **во время записи** (live notepad на экране записи). Заметки якорят LLM-саммари (Granola-паттерн) и вшиваются в `recap.md` блоком «Заметки» без переписывания.
  - Summary: рендер `*-recap.md` + Copy / Re-summarize. После авто-пайплайна (стоп → транскрипт → save → рекап) окно открывается на этой вкладке.
- Кнопки действий (Transcribe / Save / Copy for chat) — в toolbar таба, не плавающей панелью.

### Правая панель (контекстная, скрываемая)

- **Участники**: разбивка по источнику как в talat — «Микрофон» (я) и «Системный звук» (остальные). Каждый — цветной кружок-инициал, имя, меню переназначения (переименование на уровне спикера). Витрина текущей диаризации (`Speaker N` + владелец-по-микрофону); библиотеки голосов нет.
- **Теги**: v2+, пока не делаем (в бэклог).

### Запись

- Кнопка **● Запись** — справа в toolbar (как у talat), плюс текущие пути: menu bar, ⌘R в фокусе окна, Zoom-автодетект. _(Глобальный record-хоткей Ctrl+Opt+R вырезан — plan-v2 1.1; ⌃⌥N остаётся только для оверлея заметок во время записи.)_
- Во время записи контент-зона показывает ту же панель, что у готовой встречи: заголовок слева, таймер и кнопки паузы/стопа справа, живой транскрипт на месте саммари, заметки справа (`RecordingPaneHeader` + `RecordingPaneBody`).

## Поиск (⌘K, command palette)

Как в talat: модальная палитра поверх окна.

- Поле ввода + фильтры-chips: **Все / Встречи / Люди / Транскрипты**.
- Результаты: недавние записи (иконка, название, время·длительность), совпадения по тексту транскриптов.
- Секция «Действия»: Начать запись, Импорт аудиофайла.
- Исполнение: стандартный `.sheet` + `TextField` с `.searchable`-поведением, системные цвета; hairline-подсказки клавиш (↑↓ навигация, ↵ открыть, esc).

## Настройки

Двухуровневые, как в talat, но в нативном окне Settings (`Settings` scene, `⌘,`):

- Подразделы (вторая навигация слева): **Общие** (запуск при логине, поведение Dock/menu bar), **Аудио** (системный звук, эхоподавление), **Записи** (пути, авто-удаление), **Транскрипция** (gigastt, словарь терминов), **Спикеры** (пороги, калибровка), **LLM / Рекап** (провайдер, ключи, промпт), **Экспорт** (формат Simple/Obsidian), **О приложении**.
- Это перегруппировка текущего одностраничного SettingsSheet — все настройки уже существуют.
- Контролы только стандартные: `Toggle`, `Picker`, `Slider`, `TextField`, `SecureField`.

## Menu bar

Остаётся как есть (иконка, быстрый старт/стоп, Zoom-предложение), обновляются только строки на «Propeller».

## v2 — визуальные принципы из драфта (2026-07-22)

_Выведены из драфт-макета (тёмный, glassy, serif-заголовки) и сверены с каноном студии [[pgcorpus]]. **Отменяет** прежнюю установку «только системные шрифты» из раздела «Принципы» выше — по PR-011 берём характерную гарнитуру в заголовках._

1. **Editorial serif в крупных заголовках, SF во всём остальном.** Заголовок страницы («Meetings», «Summaries») — сериф (нативный New York через `.system(design: .serif)`, без бандла шрифта). Строки, body, контролы — SF. _Канон: PR-011 (характерная гарнитура хотя бы в заголовках); универсальный нейтральный шрифт — отказ от половины выразительности._

2. **Глубина через материал, не через заливку.** Тёмное «тёплое стекло»: полупрозрачный фон с мягким тёплым градиентом по краям, панели на материале, не на плоской непрозрачной заливке. Локальность читается как тёплая глубина, а не как плоский чёрный. _Отличие от текущего flat-dark._

3. **Иерархия расстоянием, не рамками.** Между строками нет разделителей и плашек — разделяет ритм и воздух. Выделение строки — тихая заливка, не громкая синяя капсула macOS по умолчанию. _Канон: PR-005 (плашка — крайнее средство; иерархию задаём расстоянием)._

4. **Цвет — только смысл.** Цвет зарезервирован под статус (точки), запись (красный) и точечные акценты. Остальное — сдержанная серая шкала. Вторичный текст приглушён, но несущий, не декоративный. _Канон: PR-006 (не глушить текст без функции)._

5. **Строка встречи — карточка воспоминания, не файл.** Заголовок (SF, medium) → сабтайтл-темы (secondary) → время (tertiary) → аватары участников справа. Читается как «что и с кем», а не «аудиофайл».

6. **Тихий статус, не хвастливый.** Системный статус (загрузка модели, обработка) живёт тихо в правом верхнем углу. Никаких лимитов/лицензий/«7h left» — локальность.

7. **Скругление и форма — решение.** Осознанные радиусы: аватары — круг, карточки — мягкое скругление, но не «скруглено всё по умолчанию». _Канон: PR-010._

8. **Русская типографика соблюдается** в пользовательских строках: длинное тире «—», ёлочки «», неразрывные пробелы после однобуквенных предлогов и перед единицами, «…» одним символом. _Канон: checks.yaml (CHK-001…006)._
