- **Активно использовать агентов.** Три параллельных `Explore` по коду окупились
  полностью: они нашли и дефект стирания заголовка, и то, что старая сборка

  сверять надо **до пикселя**.

### Чему научила сверка с макетом (не повторять)

1. **CSS экспорта врёт про маски.** `get_design_context` отдаёт `text-ellipsis`
   там, где в компоненте лежит слой-маска. Если у компонента в экспорте есть
   `isolate` и z-индексы — почти наверняка внутри маска. `get_metadata` по
   компоненту показывает её первой же строкой (`<rounded-rectangle name="mask">`).
2. **Числа брать из ассета, а не с глаза.** Ассеты качаются с локального сервера
   Figma: `curl -s http://localhost:3845/assets/<hash>.svg`. Так снят светофор
   (центры 26/46/66, не углы 24/44/64), затухание строки (`0.714 → 0.952` ширины)
   и нижняя маска списка (31,6 pt). Все три до этого были угаданы неверно.
   Ассеты протухают — если 404, перевызвать `get_design_context` на узел.
3. **Долями, а не точками**, если в макете и в приложении разная ширина: у Figma
   градиент тянется вместе со слоем.
4. **Иконки не подбирать на глаз.** Figma отдаёт их глифами приватной области
   (`\u{1008CC}`), имён ни в шрифте, ни в системных таблицах нет. Есть
   `tools/figma/symmatch.swift` — рисует глиф по кодпойнту и сравнивает со всеми
   8302 символами. Три иконки из шести в настройках были не те.
5. **Живое окно — не инструмент для замеров**: под прозрачным фоном дизеринг
   рабочего стола. Мерить по офскрин-рендерам (`RAIL_SHOT=… swift test --filter
   RailShot`, `SETTINGS_SHOT=…`), они плоские и детерминированные.
6. **Вывод сборки читать целиком.** `./build.sh --gallery | tail -2` скрыл, что
   сборка падает, и стоил часа на ложную версию «нет доступа к записи экрана».

### Параллельные сессии

Владелец запускает несколько Claude сразу. За эту сессию чужая переписывала
чёлку — дерево дважды не компилировалось не по нашей вине. **Перед тем как
чинить чужой файл, проверить `git status` и mtime**; ставить только свои файлы,
а если в общем документе (WORKLOG, CLAUDE.md, STATE.md) чужие правки — брать
только свой ханк:

```bash
git diff -- WORKLOG.md > /tmp/w.patch   # оставить первый @@-блок и git apply --cached
```

Хук `require-worklog.sh` не даст закоммитить без записи в WORKLOG.md.

## Как собрать и проверить

```bash
cd meeting-recorder/swift && ./build.sh && open -a Propeller
```

```bash
cd meeting-recorder/swift && swift test
```

На 2026-08-27 — **1103 теста, 5 пропущено, 0 падений**. Число плавает: чужая
сессия за день унесла ~19 тестов чёлки.

Галерея (последняя строка обязательна — иначе в `/Applications` останется сборка
с фикстурами):

```bash
cd meeting-recorder/swift && ./build.sh --gallery && /Applications/Propeller.app/Contents/MacOS/MeetingRecorder --gallery-export ~/Desktop/states && ./build.sh
```

Офскрин-рендеры для замеров:

```bash
cd meeting-recorder/swift && RAIL_SHOT=/tmp/rail.png swift test --filter RailShot
cd meeting-recorder/swift && SETTINGS_SHOT=/tmp/settings.png swift test --filter SettingsShot
```

Снять живое окно (Accessibility нет ни у osascript, ни у шелла — только так):

```bash
screencapture -x -o -l $(<windowID>) /tmp/win.png
```

windowID даёт утилита на `CGWindowListCopyWindowInfo`; собирается в скретчпаде за
минуту, фильтровать по владельцу `Propeller`.
