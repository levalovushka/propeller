# Propeller для коллег

Внутренний local-first рекордер созвонов: запись → русский транскрипт → саммари.
Расшифровка и саммари считаются на твоей машине.

**DoD первой раздачи:** 5 коллег × 1 неделя × ≥1 саммари без пинга автору.

## Установка

1. Скачай `.dmg` из GitHub Releases (или получи файл у Левона).
2. Открой DMG → перетащи **Propeller** в **Applications**.
3. Запусти двойным кликом. Ничего обходить не надо: сборка подписана
   Developer ID и нотаризована Apple, тикет лежит внутри — работает и без сети.
   Если macOS всё-таки ругается на «неизвестного разработчика» — это старый
   образ, скачанный до 1.16.5; возьми свежий.

## Разрешения

Первый запуск — один экран: микрофон, уведомления, запуск при входе и «Начать».
Кнопка ничем не заблокирована: отказавшийся от микрофона получит приложение,
которое честно скажет об этом на строке записи, а не стену.

| Разрешение | Зачем | Обязательно? |
|---|---|---|
| **Микрофон** | Твоя речь | да |
| **Уведомления** | Автозапись созвона и кнопка «Не записывать» в баннере | да, иначе запись стартует незаметно |
| **Календарь** | Названия встреч в списке | нет |
| **Универсальный доступ** | ⌃⌥N — заметка поверх Zoom | нет |

Системные настройки → Конфиденциальность и безопасность.

**«Запись экрана» не нужна и не запрашивается.** Вторую сторону звонка пишет
процесс-тап Core Audio, а не ScreenCaptureKit; ключа этого разрешения нет в
приложении вовсе. Если ты выдавал его ранним сборкам — можешь забрать обратно,
на запись это не влияет.

## Саммари

Расшифровка работает сразу и офлайн: модель GigaAM (~247 МБ) лежит внутри
приложения, качать нечего.

Для саммари нужна вторая модель — `qwen3.5:4b`, ~3,4 ГБ. Она качается **сама**,
в фоне, сразу после «Начать», и починяется сама, если пропадёт. Нажимать ничего
не надо, ждать тоже: записывать и расшифровывать можно с первой минуты. Пока
саммари пишется, на его месте стоит расшифровка — читать есть что.

Альтернатива локальной модели — ключ OpenAI / Claude в Настройках → Саммари.
Тогда текст встречи уходит в облако; по умолчанию не уходит никуда.

## Как пользоваться

- Созвон определяется сам — запись стартует, в уведомлении есть «Не записывать».
  Режим меняется в Настройках → Основное. Zoom проверен; для Контур.Толк
  идентификаторы записаны, но на живой установке не проверялись — если автозапись
  там не сработала, скажи Левону, это ожидаемая дырка, а не поломка у тебя.
- Руками: **⌘R** — начать, **⌘.** — остановить (откуда угодно), **⌘K** — поиск по
  расшифровкам и заметкам.
- Запись не занимает окно: встреча появляется в списке с первой секунды, и можно
  уйти читать другую, не прерывая её. На экране записи идёт живой транскрипт —
  текст отстаёт на пару секунд намеренно, так меньше ошибок.
- **⌃⌥N** во время записи — заметка с таймкодом, поверх Zoom.
- Саммари правится на месте: щёлкни в текст. Выделил фрагмент — под курсором
  панель: вид абзаца, жирное, курсив и две просьбы к модели, «Короче» и
  «Подробнее».
- ПКМ по встрече в списке — копировать саммари, поделиться, показать в Finder,
  удалить аудио, удалить встречу.

Встреча идёт по ступеням: записана → расшифрована → спикеры разделены → саммари →
темы. Каждая ступень — уже ценность, и приложение доводит начатое само: закрыл
ноутбук на середине — догонит, кнопок «Повторить» нет по устройству.

## Проблемы

- **В расшифровке только твой голос.** Значит захват свалился в mic-only. Проверь,
  что в системе есть настоящее устройство вывода (не только виртуальная карта),
  и перезапусти приложение. Замер: `open -a Propeller --args --tap-probe`, отчёт
  ляжет в Application Support.
- **Долгая встреча без расшифровки** → обнови Propeller (с 2026-07-24 длинные
  файлы режутся на чанки; раньше был HTTP 413).
- **Нет саммари** → загрузка модели ещё идёт или упёрлась в сеть; посмотри
  Настройки → Саммари. Само пройдёт, когда сеть вернётся.
- **Случайная запись на пару секунд** — встреча без звука и без текста в список не
  попадает.

## Для разработчиков

```bash
# Нужен бинарь tools/gigastt/gigastt (без него build.sh падает)
cd meeting-recorder/swift
./build.sh          # → /Applications/Propeller.app (TelemetryDeck App ID уже вшит)
./notarize.sh       # нотаризует и стейплит .app (нужен Developer ID + профиль notarytool)
./package-dmg.sh    # → ../../dist/Propeller-….dmg, подписывает и нотаризует образ
./make-appcast.sh   # → ../../dist/appcast.xml (нужен private key)
```

`.app` нотаризуется отдельно от образа, и порядок именно такой: Sparkle ставит
обновление без DMG, так что тикет должен лежать внутри бандла, иначе первый
запуск без сети упрётся в Gatekeeper. `package-dmg.sh` откажется паковать
приложение без тикета. Учётка для нотаризации живёт в связке ключей:

```bash
xcrun notarytool store-credentials propbuild --apple-id <apple-id> --team-id <team-id>
```

Обновления: меню приложения или Настройки → Основное → «О программе» →
**Проверить обновления…** (Sparkle + GitHub Releases).

Без Developer ID в связке `build.sh` спускается по лестнице: self-signed
**`MeetingRecorder Dev`** (Keychain → Certificate Assistant → Code Signing), потом
ad-hoc. Оба годятся только локально — раздавать можно лишь нотаризованное, — но
стабильная идентичность нужна, иначе каждый rebuild = заново микрофон и календарь.

Телеметрия (TelemetryDeck): по умолчанию вкл, Настройки → Основное → выкл.
Сигналы без содержания встреч: `App.opened`, `Recording.*`, `Transcription.*`,
`Recap.*`, `Setup.*`, `Onboarding.completed`, `Search.opened`, `Notice.*`,
`Pipeline.*`, `Invariant.*`, `Ollama.setup.*`. В дашборде — **Explore → Recent
Signals**, режим **Live** (release-сборки всегда Live; DEBUG из Xcode — Test).
